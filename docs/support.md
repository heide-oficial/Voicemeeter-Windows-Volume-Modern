# Support me

The Support me page collects optional ways to support the project. It does not affect audio monitoring, synchronization, or application features.

## Donate via Ko-fi

The first card explains how donations support continued development. Its Ko-fi banner opens the project's Ko-fi page in the default browser.

## Star the GitHub repository

The second card explains how starring the repository helps project visibility. **Go to repo** opens the Voicemeeter Windows Volume Modern repository in the default browser.

## Showcase the application

The third card invites users who publish a video about the application to submit it for possible inclusion on the project page. **Create video showcase post** opens a prefilled GitHub issue for the video link.

## Hiding the page

The **Hide Support me tab** option under [Appearance settings](settings.md#appearance) removes the page from the sidebar. Turning the option off restores it. External pages are opened only when the corresponding button or banner is activated.
